# OSRS Profit Tracker v4.0.0 Release Draft

Status: Draft for review
Target version: v4.0.0
Date: 2026-06-09

## Title

OSRS Profit Tracker v4.0.0: Non-GE Trading, Non-GE Analytics, and Faster Price Data

## Short Summary

Version 4.0.0 adds a full Non-GE trading area for collector and off-market items, dedicated Non-GE analytics, bulk Non-GE trading tools, a GE to Non-GE move flow, local item icons, and a set of analytics and price-data fixes.

## Post

OSRS Profit Tracker v4.0.0 is a main-version release focused on players who track more than Grand Exchange flips.

The biggest change is the new Non-GE tracker. You can now manage collector and off-market items separately from normal GE stocks, with a dedicated page, fixed catalog items, private custom items, categories, notes, archive support, and buy, sell, remove, and adjust actions. Non-GE holdings use the same average-cost accounting model as GE stocks, but they avoid GE-only assumptions like live prices, tax, buy limits, timers, alerts, graphs, and calculators.

This release also adds Non-GE analytics. Off-market trades now have their own analysis surface, making it easier to review Non-GE profit, item performance, category allocation, and category-level movement without mixing everything into the GE trading view.

Bulk trading support has been expanded for Non-GE items. You can buy or sell multiple Non-GE holdings at once, use quick action quantities, and work across categories with more predictable ordering. The table, category headers, snapshot panels, allocation bar, modals, and mobile layouts have also been tightened so the Non-GE area feels closer to the main trade page.

For users with existing GE rows that should really be tracked as off-market positions, v4.0.0 includes a Move to Non-GE flow. It creates the Non-GE holding, carries over relevant notes and history, relinks matching history rows, and removes GE-only data that no longer applies.

Item visuals should be more reliable too. The app now includes local Non-GE item icons and refreshed GE item icons, reducing dependency on external image loading during normal use.

There are several data and performance improvements in this release as well. GE price fetching now uses the app's direct Wiki price cache with reduced background polling, history has market filters, analytics view state can persist in the URL, and a long list of analytics edge cases were corrected around profit margin basis, timeframe windows, day counts, cache invalidation, top gainers, drilldowns, empty states, negative-zero displays, local time boundaries, and milestone-history backfills.

## Highlights
